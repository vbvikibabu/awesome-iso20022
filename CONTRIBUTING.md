# Contribution guidelines

Thanks for helping keep this list useful. Please follow these rules so every entry stays trustworthy.

## What belongs here

- Primary sources: official specifications, scheme announcements and bank pages. No summaries of summaries.
- Open-source libraries and tools that work with ISO 20022 payment messages and are maintained.
- Learning material that is accurate and free to read.

## What doesn't

- Marketing pages, paywalled content, and tools with no public way to try them.
- Dates or rules without a link to the body or bank that published them.

## How to add an entry

1. Search the list first to avoid duplicates.
2. Add one entry per pull request, in the right section, in this format:
   `- [Name](link) - Short description ending with a full stop.`
3. Keep the description factual and under about 20 words. No superlatives.
4. For a deadline or bank rule, link the primary source and say what it requires and from when.
5. If you maintain the project you're adding, say so in the pull request.

## Corrections

If a date, rule or link is out of date, open an issue or a pull request with the source that shows the change.
